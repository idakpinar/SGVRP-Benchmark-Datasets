# SGVRP-Benchmark-Datasets
Benchmark datasets for the Selective Generalized Vehicle Routing Problem (SGVRP)
The datasets used in this study were generated for the Selective Generalized Vehicle Routing Problem (SGVRP). The datasets are based on the benchmark instances available in the GTSPLIB database and were extended by incorporating additional problem parameters to represent the characteristics of the proposed SGVRP. Each benchmark instance includes the number of nodes (Dimension), the number of clusters (Set), the number of available vehicles (Vehicle), vehicle capacity (Capacity), maximum route duration (Tmax), the symmetric distance matrix between nodes (Edge_Weight_Section), cluster definitions (Set_Section), the prize (profit) associated with each node (Prize_Section), and the demand of each node (Demand_Section).

The fundamental structure of the datasets is derived from the GTSPLIB benchmark instances, while the parameters Vehicle, Capacity, and Tmax were added in this study to meet the requirements of the proposed SGVRP mathematical model. Detailed information regarding the original benchmark instances and the data format is available in the GTSPLIB database.
